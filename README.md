## 🏢 SaaS / Commercial Platforms



The automated online fraud detection market is dominated by specialized vendors offering chargeback guarantees, real-time ML scoring, and global identity networks. **Amazon Fraud Detector is no longer open to new customers as of November 7, 2025** — AWS recommends SageMaker AutoGluon and AWS WAF as alternatives . Pricing varies dramatically: Sift’s typical mid-market annual contract ranges **$50,000–$150,000** with implementation costs of $5,000–$20,000+ , SEON’s Starter tier is **$699/month** for 2,500 fraud checks , Kount starts at **$0.01/month** per Software Advice listing , and Forter charges based on transaction volume with implementation fees from **low to mid-five figures** .

## 🔓 Open-Source GitHub Projects



*Sorted by GitHub_Stars_Count (Descending)* 🌟



- **[Marble](https://github.com/checkmarble/marble)** [![Stars](https://img.shields.io/github/stars/checkmarble/marble?style=social&color=white)](https://github.com/checkmarble/marble/stargazers)  

  **Real-time decision engine for fraud and AML**, Elastic-2.0 licensed. **Self-hosted with Docker Compose** (4GB RAM, 10GB disk). Features: real-time transaction monitoring, customer/company screening against sanctions and PEP lists, continuous monitoring, AI-assisted investigation, audit trails, and RBAC. Data never leaves your infrastructure. Used by fintechs, banks, and crypto exchanges across 15+ countries . 🏛️



- **[PyOD (Python Outlier Detection)](https://github.com/yzhao062/pyod)** [![Stars](https://img.shields.io/github/stars/yzhao062/pyod?style=social&color=white)](https://github.com/yzhao062/pyod/stargazers)  

  **Comprehensive Python toolkit for outlier detection**, BSD-2-Clause licensed. ~8,000+ stars. 50+ detection algorithms including Isolation Forest, LOF, KNN, AutoEncoder, and COPOD. Unified API for benchmarking and deployment. **The foundational library for building custom fraud detection pipelines** . 🔬



- **[DGFraud (Deep Graph-based Toolbox for Fraud Detection)](https://github.com/safe-graph/DGFraud)** [![Stars](https://img.shields.io/github/stars/safe-graph/DGFraud?style=social&color=white)](https://github.com/safe-graph/DGFraud/stargazers)  

  **Deep graph-based fraud detection toolbox**, open-source. Implements state-of-the-art GNN-based fraud detectors including CARE-GNN, GraphConsis, and SemiGNN. **Designed for detecting coordinated fraud rings** where fraudsters collude to appear legitimate. Companion TensorFlow 2.X version available (DGFraud-TF2) . 🕸️



- **[CARE-GNN](https://github.com/YingtongDou/CARE-GNN)** [![Stars](https://img.shields.io/github/stars/YingtongDou/CARE-GNN?style=social&color=white)](https://github.com/YingtongDou/CARE-GNN/stargazers)  

  **Enhancing GNN-based fraud detectors against camouflaged fraudsters**, CIKM 2020 paper implementation. **Addresses the camouflage problem** where fraudsters mimic legitimate behavior to evade detection. Uses reinforcement learning for neighbor selection and relation-aware aggregation. **Critical for detecting sophisticated fraud rings** . 🎭



- **[realtime-fraud-detection-with-gnn-on-dgl](https://github.com/awslabs/realtime-fraud-detection-with-gnn-on-dgl)** [![Stars](https://img.shields.io/github/stars/awslabs/realtime-fraud-detection-with-gnn-on-dgl?style=social&color=white)](https://github.com/awslabs/realtime-fraud-detection-with-gnn-on-dgl/stargazers)  

  **AWS Labs end-to-end GNN fraud detection architecture**, Apache-2.0 licensed. **Production blueprint** using Amazon Neptune (graph database), SageMaker, and Deep Graph Library (DGL). Constructs heterogeneous graphs from tabular data and trains GNN models for real-time transaction fraud detection on IEEE-CIS dataset. **The reference architecture for graph-based fraud detection at scale** . 🏗️



- **[Fraud-Detection-Handbook](https://github.com/Fraud-Detection-Handbook/fraud-detection-handbook)** [![Stars](https://img.shields.io/github/stars/Fraud-Detection-Handbook/fraud-detection-handbook?style=social&color=white)](https://github.com/Fraud-Detection-Handbook/fraud-detection-handbook/stargazers)  

  **Reproducible machine learning for credit card fraud detection**, open-source. **Complete practical handbook** covering feature engineering, model selection, performance metrics, and deployment. Uses the ULB Credit Card Fraud dataset. **The definitive educational resource for building production fraud detection systems** . 📚



- **[sentinelpay](https://github.com/ShauryaNCode/sentinelpay)** [![Stars](https://img.shields.io/github/stars/ShauryaNCode/sentinelpay?style=social&color=white)](https://github.com/ShauryaNCode/sentinelpay/stargazers)  

  **Real-time UPI fraud detection with ML ensemble**, open-source. National Finalist at Secure AI Hackathon, BITS Goa. **XGBoost (supervised) + Isolation Forest (unsupervised) 70/30 ensemble** for single 0–100 risk score. **HMAC-SHA256 request signing** with replay attack prevention. **Hash-chained audit log** detects tampering. **Adversarial probe detection** identifies threshold reverse-engineering. Sub-100ms inference. Flutter frontend with real-time risk gauge . 🇮🇳



- **[Fraud-Detection-Model](https://github.com/ibtesaamaslam/Fraud-Detection-Model)** [![Stars](https://img.shields.io/github/stars/ibtesaamaslam/Fraud-Detection-Model?style=social&color=white)](https://github.com/ibtesaamaslam/Fraud-Detection-Model/stargazers)  

  **End-to-end ML pipeline with explainability**, open-source. **4-model benchmark** (Logistic Regression, Random Forest, XGBoost, LightGBM). **SMOTE class balancing** for 0.17% fraud rate. **SHAP per-prediction explainability** for regulatory compliance. **DistilGPT-2 plain-English summaries** of why transactions were flagged. Interactive Streamlit dashboard and automated Markdown reporting . 📊



- **[StalkPhish](https://github.com/t4d/StalkPhish)** [![Stars](https://img.shields.io/github/stars/t4d/StalkPhish?style=social&color=white)](https://github.com/t4d/StalkPhish/stargazers)  

  **Phishing kit stalker and harvester**, open-source. **Harvests phishing kits for investigations** — identifies and collects the tools fraudsters use to create fake login pages. **Complements transaction fraud detection** by targeting the phishing infrastructure itself. Companion tool PhishingKitHunter finds kits using your brand assets . 🎣



- **[AMLSim](https://github.com/IBM/AMLSim)** [![Stars](https://img.shields.io/github/stars/IBM/AMLSim?style=social&color=white)](https://github.com/IBM/AMLSim/stargazers)  

  **Multi-agent based AML simulator**, Apache-2.0 licensed. **Generates synthetic banking transaction data** with known money laundering patterns. Purpose-built for **testing ML models and graph algorithms** when real AML datasets are unavailable due to privacy constraints. From IBM Research . 🧪



- **[TabFormer (IBM)](https://github.com/IBM/TabFormer)** [![Stars](https://img.shields.io/github/stars/IBM/TabFormer?style=social&color=white)](https://github.com/IBM/TabFormer/stargazers)  

  **Tabular transformers for modeling multivariate time series**, Apache-2.0 licensed. ICASSP 2021 paper code. **Applies transformer architecture to tabular fraud data** — captures complex feature interactions that tree-based models miss. State-of-the-art results on credit card fraud detection benchmarks . 🤖



- **[self-organizing-maps (Fraud Detection)](https://github.com/giorgioroffo/self-organizing-maps)** [![Stars](https://img.shields.io/github/stars/giorgioroffo/self-organizing-maps?style=social&color=white)](https://github.com/giorgioroffo/self-organizing-maps/stargazers)  

  **SOM template for banking fraud detection**, open-source. **Unsupervised anomaly detection** using Self-Organizing Maps. **No labeled fraud data required** — learns normal transaction patterns and flags deviations. Useful for detecting novel fraud types not present in training data . 🗺️



- **[getIPIntel](https://github.com/blackdotsh/getIPIntel)** [![Stars](https://img.shields.io/github/stars/blackdotsh/getIPIntel?style=social&color=white)](https://github.com/blackdotsh/getIPIntel/stargazers)  

  **IP intelligence and proxy/VPN/TOR detection**, open-source. **Free API** to block proxies, VPN connections, web host IPs, TOR nodes, and compromised systems. **Prevents fraud by identifying masked origins** — critical for account creation and payment fraud detection. Includes GeoIP lookup . 🌐



- **[januusio/cryptowallet_risk_scoring](https://github.com/januusio/cryptowallet_risk_scoring)** [![Stars](https://img.shields.io/github/stars/januusio/cryptowallet_risk_scoring?style=social&color=white)](https://github.com/januusio/cryptowallet_risk_scoring/stargazers)  

  **Explainable crypto wallet risk scoring**, open-source. **Fully explainable scoring** for cryptocurrency wallets. **Every risk factor is documented and auditable** — no black-box scoring. Essential for AML compliance in crypto exchanges and DeFi platforms . ₿
